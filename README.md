# APA Doc Formatter

A full-stack web application that analyzes and formats Word documents into APA style without modifying the original file.

## Features

- Upload `.docx` files for analysis
- Detect formatting issues in APA-style documents
- Automatically generate a corrected Word document
- Download the formatted version
- FastAPI backend
- Vite frontend

## Tech Stack

### Backend
- Python
- FastAPI
- python-docx

### Frontend
- React
- Vite
- JavaScript / TypeScript
